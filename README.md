## Kotlin Hello World

This repository also includes a simple "Hello World" program written in Kotlin.

### Running the Kotlin Program

To compile and run the Kotlin program:

```bash
./run-kotlin.sh
```

Or manually:

```bash
# Compile to JAR
kotlinc HelloWorld.kt -include-runtime -d HelloWorld.jar

# Run the program  
java -jar HelloWorld.jar
```

**Prerequisites:** 
- Kotlin compiler (`kotlinc`)
- Java runtime (`java`)
